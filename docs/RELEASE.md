# 轻桌面 2.33 / M13 Light Launcher

在盒子上看电影、听音乐、投屏，也能直接编辑课程和管理设置。此版本包含此前未单独发布的 2.32 首页与音乐改进。

## 本次更新 / What's new

- 首页焦点更清楚，长按可置顶或调整顺序；返回后保留焦点和滚动位置，电视边距可调。
- 轻音乐新增极简全屏、四档歌词字号、顺序／单曲循环／随机播放、睡眠定时及重试入口。
- 遥控器直接编辑每周课程，支持指定日期调课和放假，屏保跳到下一上课日；天气缓存明确标注观测时间。
- 投屏状态更清楚，按返回停止本次投屏并回到先前页面。
- 设置可在盒子本机备份、恢复、撤销；可检查 GitHub 正式版、查看更新内容并保留安装包。账号和设备管理信息不包含在设置备份里。

Clearer TV focus, home ordering, preserved navigation and overscan margins. Music gains fullscreen lyrics, font sizes, playback modes and sleep pause timers. Edit weekly courses and date exceptions with the remote, restore settings locally, and discover public GitHub updates directly on the box.
